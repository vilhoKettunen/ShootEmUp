## Teacher's brief (Finnish, summarized)

- Simple 2D game: collisions have NO physics; the collider or the target (or both)
  DIE. Handle in `OnTriggerEnter2D`; the essence is "which object touches which, and
  how do we react" — done with TYPES (not tags), mostly `TryGetComponent`, plus `is`
  where it fits (bullet).
- FIRST check these are set up:
  - 2D TRIGGER colliders on bullets, enemies, collectables.
  - Trigger collisions require at least ONE of the pair to have a Rigidbody2D — in
    this build the Rigidbody2D is on Bullets + Player.
  - An EnemyBulletBasic prefab was made (movement = down); ADD it to the pool list
    so enemy bullets can be fetched from the pool.
- Then the code changes in these scripts:
  - **PlayerController**: fires the active weapon (bullet from pool, owner=player,
    weapon damage); `OnTriggerEnter2D` checks (TryGetComponent) Collectable →
    `Collect()`, Enemy → player takes damage; `TakeDamage(amount)` reduces HP and
    calls `Die()` at 0.
  - **Enemy**: `StartFiring()` uses an Awaitable delay (see the Shoot 'Em Up tab) and
    calls `Shoot()` every second while alive; `Shoot()` gets a bullet from the pool,
    owner = enemy; `TakeDamage(amount)` reduces HP, calls `Die()` at 0.
  - **Bullet**: `SetOwnerAndDamage(owner, damage)` stores owner + damage and RETURNS
    this (chains after Get); `OnTriggerEnter2D` uses `is`: player's bullet damages
    enemy, enemy's bullet damages player; after a hit the bullet returns to the pool.
    (Same Bullet class for player AND enemy bullets — owner is the difference.)
  - **Collectable + SpaceObject**: `Collectable.Collect()` logs + hides sprite (test);
    `SpaceObject.Die()` sets IsAlive=false + logs; `Die()` is VIRTUAL for later
    per-class death.
- CLOSING: this is the last major addition before the autumn break. After it, the
  game has its base "architecture" + core mechanics (partly test versions).
  DELIVERY (next week, from the brief): finish all game tasks → return a BUILD that
  runs without errors + an on-site code review presenting the key parts.
