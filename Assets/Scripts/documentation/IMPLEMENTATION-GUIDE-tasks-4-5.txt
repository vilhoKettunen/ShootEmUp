## 3. WHAT YOU NEED TO DO (Unity Editor + Testing)

### 3.1 Unity Editor: Create the pool config asset (BLOCKING — pool won't work without this)

1. In the Project window: **Create → Game → Pool Space Objects**
2. Name it `PoolSpaceObjects` and save it to **`Assets/Resources/`** (MUST be in a
   Resources/ folder for `Resources.Load<SOPoolSpaceObjects>("PoolSpaceObjects")`).
   If `Assets/Resources/` doesn't exist, create it first (right-click → Create → Folder).
3. Add PoolEntry rows (defaults from Q-T4-6):

   | Prefab (pick the SpaceObject COMPONENT) | initialSize |
   |------------------------------------------|-------------|
   | Player Bullet (PlayerBullet_MG prefab → its Bullet component) | 20 |
   | Enemy Bullet (EnemyBulletBasic prefab → its Bullet component) | 20 |
   | Enemy Vulture (EnemyVulture prefab → its EnemyVulture component) | 10 |
   | Enemy Falcon (EnemyFalcon prefab → its EnemyFalcon component) | 10 |
   | TestDummy (TestDummy prefab → its TestDummy component) | 1 |

   > The `prefab` field is a **SpaceObject COMPONENT** reference — when you click
   > the object picker, select the **prefab's Bullet / Enemy / ... component**, not
   > the GameObject. The Inspector will show the component name.

### 3.2 Unity Editor: Verify prefab setup (BLOCKING — collisions won't fire)

For EVERY pooled prefab (PlayerBullet, EnemyBulletBasic, Vulture, Falcon, TestDummy,
Collectable):

- [ ] **Exactly ONE** SpaceObject-derived script on the prefab root (§2.2 rule).
- [ ] **Collider2D** (BoxCollider2D / CircleCollider2D) with **Is Trigger = ON**.
- [ ] **Rigidbody2D** with **Gravity Scale = 0** (required for 2D trigger events to fire).
  - Per the brief: Rigidbody2D on Bullets + Player. EnemyBulletBasic needs one too.
  - Enemies + Collectables + Obstacles also need one for their trigger pairs.

### 3.3 Unity Editor: Create EnemyBulletBasic prefab (BLOCKING — enemies can't fire)

1. Create a new prefab `Assets/Prefabs/Bullets/EnemyBulletBasic`:
   - Bullet script (the SAME `Bullet.cs`)
   - An enemy bullet sprite (any small projectile sprite)
   - BoxCollider2D (Is Trigger ON) + Rigidbody2D (Gravity 0)
   - Set the serialized `movementParameters` field on the Bullet to a SOMovementParameters
     asset with **Direction = DOWN** (0, -1), Speed ~8, Pattern = Straight.
     (Create a new SO: Create → Game → Movement Parameters, name it e.g. "EnemyBulletDown".)
   - Set `defaultDamage = 1` (or whatever you want).
2. Add it to the `PoolSpaceObjects` asset (row 2 in §3.1).

### 3.4 Unity Editor: Assign enemy weapon (BLOCKING — enemies can't fire)

1. Create a weapon SO for enemies:
   - **Create → Game → Weapon Specs** → name it `EnemyBasicWeaponSpecs`
   - Set: `weaponName = "Enemy Basic"`, `bulletPrefab = EnemyBulletBasic`,
     `bulletMovement = EnemyBulletDown` (the SO from §3.3), `fireInterval = 1.0`,
     `baseDamage = 1`, `damagePerLevel = {1}`.
2. On the **Vulture** and **Falcon** prefabs: set the `weapon` field (on the
   Enemy component) to `EnemyBasicWeaponSpecs`.
   - Also set `fireInterval = 1.0` and `startHealth = 10` (or your preferred values).

## 5. TROUBLESHOOTING (quick map)

| Symptom | Likely cause / fix |
|---|---|
| "[ObjectPool] not registered" on Get | Prefab missing from PoolSpaceObjects list, or `InitObjectPool()` not run (§3.1). |
| "returned but never created from a registered prefab" | A non-pooled object was Returned (e.g. the player). Use Despawn for the player. |
| Bullet/enemy "resurrects" then NullRef | You called `Destroy` on a pooled object (must be `pool.Return`). |
| Hierarchy count climbs during firing | Not recycling (still `Destroy`) OR double-Return (same instance enqueued twice). |
| Enemy bullets fly UP instead of DOWN | EnemyBulletBasic movement SO direction is wrong (should be DOWN / (0,-1)). |
| No enemy→player damage at all | Collider missing "Is Trigger: ON" or Rigidbody2D missing on the bullet (§3.2). |
| Player self-damages on fire | Friendly-fire guard missing (Bullet.OnCollision, Q-T5-3). |
| Enemy keeps firing after death | `Die()` must set `IsAlive=false` before `pool.Return`, and `ResetObject` must stop the coroutine. |
| Enemy doesn't fire at all | `weapon` field null on the enemy prefab (§3.4). |
| Bullet doesn't move | `movementParameters` field null on the bullet prefab (§3.5). |
| "PoolSpaceObjects asset not found" | Asset not in a `Resources/` folder (§3.1). |
