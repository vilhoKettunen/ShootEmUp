## Teacher's brief (Finnish, summarized)

- Add Kryzarel's C# easing functions to the project (link to gist provided).
- Create a general `MovementPatterns` class: common movement patterns usable by
  BOTH enemies and bullets. Starts with THREE patterns: Straight, Sine, MoveToTarget.
- `MovementPatterns` functions are PURE FUNCTIONS: no Unity connection, reusable in
  any C# project. Functions take a `SOMovementParameters` object as a parameter.
- `SOMovementParameters` is a ScriptableObject: defines the pattern, direction,
  speed, optional sine amplitude/frequency, and the MoveToTarget destination.
- `Bullet` is a NEW class, also inherits `SpaceObject` (Task 1 base).
- For testing: Awake + Update methods that initialize and run the patterns with
  each object's own SOMovementParameters values (different per enemy / bullet).
- Build prefabs: EnemyGreenSlime, EnemyPinkBall, a PlayerBullet, plus the related
  SOMovementParameters assets. Test the movement with two enemies + one bullet.
- OUT OF SCOPE for this stage: instantiation / destruction / collision of enemies
  and bullets (but DO build the prefabs for the next stages).
