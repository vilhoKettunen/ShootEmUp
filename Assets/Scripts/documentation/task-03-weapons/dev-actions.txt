## Teacher's brief (Finnish, summarized)

- Build a WEAPON system: 3 clearly different weapon types, each with 5 efficiency
  levels (damage / speed / count scale with level). Design for easy extension.
- Start with a DATA class: `SOWeaponSpecs` (ScriptableObject) defines the weapon and
  links its graphical representation + Bullet prefab to a specific weapon.
- `Weapon` class (used by PlayerController, e.g. `currentWeapon = new Weapon(specs)`)
  holds the weapon STATE and has methods to upgrade / reset the current weapon system
  (`IncreaseLevel`, `ResetLevel`).
- `Bullet` already exists (Task 2) but needs COLLISION DETECTION + HANDLING so the
  whole chain works and "shooting enemies" is demonstrable.
- `fireRate` (fire interval) stays the PLAYERS' responsibility per the brief; a
  single bullet's DAMAGE is passed to the Bullet, e.g. via Init/Spawn, depending on
  the player's current weapon level.
- Once SOWeaponSpecs + Weapon exist: create prefabs for at least TWO weapons
  (MachineGun + EnergyRing, per the reference screenshot), each with its own
  Bullet prefab + SOMovementParameters, create the SOWeaponSpecs assets, and test
  actual firing with small changes to PlayerController
  (`currentWeapon = new Weapon(DefaultWeapon);` where DefaultWeapon is a
  SOWeaponSpecs reference assigned in the Inspector).
- Reference layout (screenshot): prefabs PlayerBullet_Ling / PlayerBullet_MG,
  SO assets EnergyRingWeaponSpecs + MachineGunWeaponSpecs, classes
  SOWeaponSpecs, Weapon, Bullet, Collectable.
